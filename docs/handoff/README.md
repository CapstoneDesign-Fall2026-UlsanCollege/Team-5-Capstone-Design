# Handoff Guide

This page helps a teammate or reviewer open the project, understand what exists, and continue documentation without guessing.

## How To Open The Prototype

1. Open `Frontend/index.html` in a browser.
2. Try the subject, task, completion, and quiz flow.
3. Use browser storage tools or a fresh profile to reset local demo data.

No package install or build step is required for the current prototype.

## Important Paths

| Path | Purpose |

| `README.md` | Public project summary |
| `Frontend/index.html` | Runnable browser prototype |

## Known Limits

- The current prototype is not a React + Vite app.
- Week 6 independent proof is not complete until another tester records actual results.
- Backend, login, AI generation, and cloud sync are not part of the current MVP evidence.

## Maintainer Notes

- Keep weekly docs linked from `docs/README.md`.
- Keep project claims consistent with [Project status](../PROJECT_STATUS.md).
- Use `Pending`, `Blocked`, or `Not run` when proof is missing.
