# Week 5 — API Design

This folder contains the API design for the Smart Study Companion project.

## Contents

- [API Design](API-Design.md)

## Purpose

The API design describes how the application will manage:

- subjects
- study tasks
- deadlines
- a study plan
- quizzes
- quiz results

This design keeps the project simple for the MVP while leaving room for future improvements such as AI-generated content, reminders, and user accounts.
