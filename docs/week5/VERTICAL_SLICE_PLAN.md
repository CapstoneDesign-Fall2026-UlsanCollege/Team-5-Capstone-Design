# Week 5 Vertical Slice Plan

This plan defines the small visible behavior that Week 6 tested with screenshot proof.

## Slice

A student can open the prototype, choose or create a subject, add a task, review the task in the study plan, complete the task, take a quiz, see a score, and confirm browser storage keeps the main data after refresh.
