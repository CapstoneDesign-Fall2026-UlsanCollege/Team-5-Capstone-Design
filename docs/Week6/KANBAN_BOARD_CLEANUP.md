# Week 6 Kanban Board Cleanup Note

Use the project board to show the real status of the Week 6 evidence work and the next midterm preparation tasks.

## Status Meaning

| Board status | Meaning | Example Week 6 item |
|---|---|---|
| Backlog | Future or optional work that is not needed for the current evidence package | Later feature ideas or extra stretch tasks |
| Ready | Clear next action that can be picked up by a teammate | Midterm rehearsal or issue cleanup task |
| In progress | Work actively being changed or tested | Theme/color consistency fix |
| In review | Work waiting for review before merge or final acceptance | PR #24 and Week 6 evidence docs |
| Done | Completed work with evidence already linked | Past setup, planning, wireframes, and prototype proof |

## Cleanup Rule

Do not leave every issue in Backlog. Move cards when the status changes so another teammate can understand what is finished, what is being reviewed, and what still needs action.
