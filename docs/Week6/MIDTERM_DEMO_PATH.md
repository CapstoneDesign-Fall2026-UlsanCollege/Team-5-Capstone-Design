# Midterm Demo Path

**Goal:** show one clear student path through Smart Study Companion in 2-4 minutes.

## Demo Script

1. Open `Frontend/index.html` and show the main study-planner screen.
2. Create or select one subject and add one study task with a deadline.
3. Open the study plan and show the task in the planned list.
4. Mark the task complete and show the updated completion state.
5. Open the quiz flow, answer the questions, submit, and show the score.
6. Refresh the page and show that saved task or quiz data remains.
