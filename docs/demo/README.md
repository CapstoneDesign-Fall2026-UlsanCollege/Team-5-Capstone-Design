# Demo Documentation Guide

This guide defines what the team should capture for midterm and final demos.

## Midterm Demo Package

| Item | Needed evidence |
|---|---|
| Demo script | Short step-by-step flow from subject to quiz score |
| Screenshot set | Home, study plan, completion state, quiz, result |
| Known limits | Honest list of missing or pending features |
| Test result | Manual test note with expected and actual behavior |
| Proof link | Commit, PR, issue, screenshot folder, or demo video |

## Final Demo Package

| Item | Needed evidence |
|---|---|
| Final user flow | Complete student workflow from setup to quiz feedback |
| Feature summary | What is implemented and what is not |
| Test summary | Manual test table with pass/fail/not-run results |
| Handoff notes | Setup, run steps, and known limitations |
| Contribution summary | Member rows with evidence links |

## Demo Rule

Only show work as complete when the repository or proof link demonstrates it. If something is still planned, mark it as planned.
