# Smart Study Companion

**Team:** DJ Barut
**Course:** Capstone Design — Fall 2026
**Last updated:** 2026-09-15

## What this project is

Smart Study Companion helps college students organize their study tasks, remember assignment and exam deadlines, and prepare for exams with a simple study planner and multiple-choice quiz system in one place.

## Target users

- Primary user: college students
- Secondary user: none for the MVP
